# Manifest for llms-full.txt.
#
# Every Markdown file tracked in this repository must appear here exactly once,
# as either an `include` or an `exclude`. scripts/generate-llms-full.sh fails if
# one is missing from both lists, so a new document cannot enter the repository
# without a deliberate decision about whether it belongs in the bundle.
#
# Format, one directive per line:
#
#   include <path>            bundled into llms-full.txt, in the order below
#   exclude <path>  # reason  deliberately left out
#
# Blank lines and lines starting with # are ignored. Paths are relative to the
# repository root.
#
# The order of `include` lines is the order of the bundle: root documentation
# first, then the material an agent needs to understand the images, then the
# deployment paths (Helm, Compose, examples). Keep related documents together.
